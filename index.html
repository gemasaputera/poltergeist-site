Errors you stop scrolling past

Reads your errors for you

The ghost reacts to the real warning or error in the file you are editing, so every line is about your actual code.

Notices when you stop

Go idle and the ghost creeps in to ask if you are still there. You set how long it waits.

Works with your model

Use Ollama on your own machine, or any OpenAI compatible API. Switching is one setting.

Keeps your code home

In local mode nothing leaves your computer. In hosted mode only the error message is sent by default.

Questions people ask first

Does my code leave my computer?

Not in local mode. In hosted mode, code context is off by default, so only the error message is sent to your provider. You can turn code context on in settings.

Which models does it work with?

Any OpenAI compatible endpoint. That includes Ollama on your machine and hosted open weight models such as DeepSeek and Xiaomi MiMo.

Does it work offline?

Yes, with a local model through Ollama. Hosted mode needs an internet connection.

Will the ghost interrupt my work?

No popups and no panels. The status bar pill expands for a few seconds, then shrinks back. A cooldown stops it from speaking too often.

Which ghosts are included?

COBOL, Perl, and ActionScript. Switch between them with the Pick Ghost command.

What does it cost?

The extension is free. Local mode costs nothing per line. In hosted mode your provider bills you, and one short line uses very few tokens.
